# Tips_SE

演劇用の効果音ポン出しアプリ（Windows専用）の配布用リポジトリです。

## ダウンロード

最新版は [Releases](https://github.com/Ka-Hiromu/Tips_SE-dist/releases/latest) から
`Tips_SE_*.zip` を取得してください。

1. ZIP をダウンロード
2. **展開する前に** ZIP を右クリック → プロパティ → 「セキュリティ」の「許可する」にチェック → OK
3. ZIP を展開し、`Tips_SE\Tips_SE.exe` を実行

Python のインストールは不要です。

## 動作環境

- Windows 10 / 11（64bit）
- オーディオ出力デバイス（WASAPI）

## 補足

- 設定とログの保存先: `%LOCALAPPDATA%\Tips_SE\`
- 本体は未署名のため、初回起動時に Windows の警告が表示される場合があります。
- 詳しい使い方は別途配布する説明書を参照してください。
